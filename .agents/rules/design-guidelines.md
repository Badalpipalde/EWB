# Design Guidelines — Anti-Vibe-Coded UI


## Always do work like senior software developer use clean code structure , also you are the best software developer and ui developer , when u create it feels like something great.


## Ditch the AI Design Clichés
- **No purple gradients.** Indigo-to-purple fades are the biggest giveaway. Use solid, muted backgrounds or high-contrast monochromatic themes.
- **Stop centering everything.** Use traditional grid structures, left-align text, and anchor elements to screen edges.
- **Kill fake glow effects.** No random radial gradients or neon floating lights behind hero sections.

## Fix Typography and Hierarchy
- **Avoid mono-weight text.** Don't use the same font weight and size everywhere (e.g., Inter at 100% uniformity). Create a visual path for the eye.
- **Create scale.** Use massive headlines paired with small, high-legibility body text for clear contrast.
- **Limit your palette.** One dominant color, one intentional accent, one clean neutral. Not five competing bright hues.

## Inject Real Human Intent
- **Use visual references.** Feed specific design system instructions (exact 8px spacing rules) or reference screenshots from Dribbble/Behance. Don't one-shot frontends.
- **Replace vague copy and icons.** No generic sparkle icons, repetitive feature grids, or placeholder emojis. Use product-specific messaging, real screenshots, or real photography.
- **Refine the last 20% manually.** AI gets 80% fast; the final human-driven polish strips the generic look.
